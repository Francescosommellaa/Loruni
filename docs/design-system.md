# Design system — fondamenta e stato Fase 03

Contratti e valori eseguibili: packages/ui/src/brand.ts e styles.css; le componenti usano CSS Modules. DESIGN.md conserva il contesto visivo e descrive la base effettiva; il sidecar Impeccable è derivato.

- Palette esistente preservata, senza nuove tinte definitive. brand.ts è la sola fonte dei quattro hex e dei percorsi asset; i layout espongono brandVariables, manifest/social consumano gli stessi valori.
- Ruoli colore: background/secondary, surface/elevated, text/secondary/muted, accent/on-accent, positive, border, focus. Fase 03 aggiunge depth (background 80% + black) e media-shade (grafite 88% + transparent), senza nuova tinta di marca. Ruoli di tema ricalcolati nello scope chiaro; app/eventi è la pausa avorio, gaming resta scuro. Corallo sulle frecce di visita; lime non distribuito per obbligo.
- Funnel Display per poster/scene/display/heading, Funnel Sans per body/UI; variabili locali next/font/local con OFL. Dieci ruoli data-type: poster, scene, display, heading-1/2/3, body-large, body, small, label. Poster/scene sono riusati dalle scene Fase 03; il massimo 6rem resta soltanto del display. Metriche normative in DESIGN.md, source CSS condivisa; gerarchia HTML distinta dal ruolo visivo.
- Spacing ridotto invariato: xs/sm/md/lg/xl e 2xl/3xl fluidi. Nessuna scala di pagina parallela; la composizione usa i token condivisi.
- Container: massimo 72rem e gutter fluido 1–2rem, centratura. Section: padding verticale tramite section-space, nessun gutter. Gap dei figli dal parent; nessun margin esterno dei controlli.
- Button: altezza minima 3rem, padding sm/lg, gap sm, radius-control 0, variant semantiche primary/secondary, focus/hover/active/disabled. Nessuno spostamento attivo decorativo.
- Switch: target 52×44px, track/thumb e label/state accessibili; bordo semantico rende distinguibile il track anche lime su avorio. Dimensioni/20px di radius track sono geometria meccanica locale preesistente, non una superficie o una scala radius di pagina.
- CSS feedback 120ms, switch 160ms, preferenza reduced motion immediata. Nessuna animazione narrativa di riferimento già scelta.

Baseline accessibile: focus visibile, skip link, HTML semantico, controlli nativi da tastiera e target ≥44px per la base. Contenuti server disponibili anche senza JS o motion. Questo documento non attesta un audit WCAG completo; prove e limiti in docs/verification.md.

Stato verificato nel codice il 2026-10-02: home Fase 03 statica cinematico/editoriale, otto scene server e un H1. Poster per apertura/socialità/cocktail/convergenza/visita, scene per tavolo/digitale/espansione, heading-2 per app/eventi e link menu (heading-1 da desktop). Claim e fotografia precedono il registro inferiore logo/Napoli; nessuna eyebrow o attesa iniziale. Copy provvisorio, quattro reference sintetiche dichiarate, schermate app/store mancanti. Non è approvazione editoriale finale né una comp generata approvata. Prossima fase: Motion System + Scroll Choreography.

La landing possiede soglie locali 48rem (tablet composto, sei tracce quando servono) e 64rem (dodici tracce/overlap desktop); le fondamenta non introducono breakpoint globali. Tavolo/app mobile a una colonna, cocktail/convergenza mantengono griglie fotografiche locali. Container possiede larghezza/gutter, scena ritmo/minimi svh, grid/flex gap. Il contenuto può allungare le scene al reflow. Fotografie fill/cover, sizes e crop di scena, B/W episodico; watermark ufficiale come finestra/strato/eco. Queste composizioni non sono un registry condiviso. Il playground resta Operate; QA 390×844, 768×1024, 1440×900 e reflow/zoom pertinenti.

ReferencePhoto e JourneyLink sono locali alla landing: figura/dichiarazione sintetica e CTA editoriale con freccia SVG; ButtonLink dello scaffold è rimosso senza consumer. Store assente usa Button secondary disabilitato con nota. Nessuna Card o famiglia media generica estratta. Main isolation delimita layer media locali; layer-navigation 1 e layer-skip-link 2 sono semantici, dialog nel top layer nativo.

Il reveal CSS Fase 02 è rimosso. Navbar e progressione sono locali; altezza misurata `--journey-nav-height` per ancore/tema, cleanup ResizeObserver/listener/RAF. Dialog fullscreen con focus/ESC, ripristino overflow e preview fotografica su hover/focus. Landing senza GSAP, pinning, smooth scroll, cursore o motion narrativo definitivo. GSAP/ScrollTrigger restano lazy e scoped attraverso @loruni/ui/motion nel playground, reduced motion reattivo e cleanup obbligatorio.
